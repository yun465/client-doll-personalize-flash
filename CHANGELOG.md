## [0.1.0] - 2026-09-12

### Added

- Bilingual installation and usage documentation.
- Explicit distinction between the reusable workflow and the non-included companion firmware.
- Project adaptation contract for non-reference firmware projects.
- Sanitized persona approval example.
- GitHub Actions validation, contribution guidance, security policy, and Issue forms.
- Social preview artwork.

### Changed

- Reduced machine-specific paths and execution-mode assumptions in `SKILL.md`.
- Moved firmware constants behind an explicit reference-profile compatibility check.
- Clarified independent authorization gates for chat, audio, build, device writes, credentials, and real cloud calls.
